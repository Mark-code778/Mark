# Map Explainer — фирменный стиль канала

Канал **на русском языке**: сценарий, диктор, подписи на карте, титры, описание и теги — всё по-русски.
Километры (не мили), десятичная запятая («3,8 км»), пробел в тысячах («12 000»), кавычки «ёлочки», тире «—».
Обращайся к пользователю по-русски.

Эталон жанра: «Почему 80 американцев живут в 3,8 км от России». Нет лица, нет съёмок — только карта, камера и голос.

## 0. Где что лежит

| Что | Где |
|---|---|
| Движок (Remotion-проект, 1920×1080, 30 к/с) | `map-studio/` в корне репозитория |
| Эталонная копия движка | `.claude/skills/map-explainer/engine/` (если `map-studio/` нет — скопируй оттуда) |
| Ролик | `map-studio/videos/<slug>/` → `script.md`, `shots.json`, `voiceover.mp3`, `timeline.json` |
| Готовое | `map-studio/out/` → `video.mp4`, `frames.jpg`, `upload.md` |
| Пример всех элементов стиля | `engine/videos/_styletest/shots.json` |

Развернуть с нуля:
```bash
cp -r .claude/skills/map-explainer/engine map-studio && cd map-studio
npm install && npm run fetch-assets        # Natural Earth + шрифты с кириллицей
pip install faster-whisper                 # для привязки к озвучке
```
Нужны хосты: `gibs.earthdata.nasa.gov` (снимки), `raw.githubusercontent.com` (Natural Earth),
`fonts.googleapis.com`/`fonts.gstatic.com`, `huggingface.co` (модель Whisper). Node-скрипты запускаются через
`npm run …` — там уже стоит `NODE_USE_ENV_PROXY=1` для прокси.

**Стиль живёт в коде движка** (`src/lib/theme.ts` и компоненты). Для конкретного ролика код движка не меняй —
ролик описывается только через `shots.json`. Улучшения стиля вноси в движок и копируй в `engine/`,
чтобы все будущие ролики их получили.

## 1. Конвейер (по шагам, с остановками)

1. **Идеи** → 10 штук: реальное странное место на карте + число в названии (расстояние, население, время).
   Название < 60 символов, хук в одну строку. СТОП — ждать выбора.
2. **Сценарий** `script.md` (~1400 слов ≈ 9 мин при 150 сл/мин) + **`shots.json`** (один кадр на одну строку
   текста диктора). СТОП — ждать озвучку.
3. **Озвучка** кладётся в `voiceover.mp3` → `npm run align -- <slug>` → `timeline.json`.
4. `npm run prep -- <slug>` — скачивает снимки, режет геоданные, пишет `public/current/`.
5. Рендер: `npx remotion render src/index.ts MapExplainer out/video.mp4` (для первой минуты добавь `--frames=0-1799`).
6. **Проверочные кадры**: `npm run frames -- out/frames.jpg <кадр> <кадр> <кадр> <кадр>` → открыть картинку
   и самому сверить с чек-листом (раздел 8). Исправить, перерендерить.
7. **`out/upload.md`**: 3 варианта названия, описание с главами (тайм-коды из `timeline.json`), 15 тегов, идея превью.

## 2. Визуальный стиль

### Снимки (только бесплатные и реальные — NASA GIBS, WMS, EPSG:4326)
- **Дальние и средние планы** (> 300 км в кадре): `BlueMarble_ShadedRelief_Bathymetry` — рельеф суши + синий океан.
- **Крупные планы** (< 300 км, полностью к 160 км): `Landsat_WELD_CorrectedReflectance_TrueColor_Global_Annual`
  — 30 м, без облаков. Плавный переход между слоями делает движок сам.
- **Космос/глобус** (> 6000 км): та же Blue Marble, натянутая на ортографический глобус с атмосферой и звёздами.
  Переход «глобус → плоская карта» внутри одного движения камеры — автоматически (6000–10 000 км).
- **Сверхкрупные планы** (< 5 км, отдельные здания и островки): Landsat 30 м здесь превращается в кашу.
  Нужен открытый аэрофотоснимок (национальные ортофото с открытой лицензией) — без него не делай кадры уже 5 км.
- Цветокоррекция одна на весь канал: `brightness(0.84) saturate(0.92) contrast(1.08)` + виньетка.
- Не используй Google/Bing/Mapbox и любые платные/закрытые подложки.

### Векторные данные — Natural Earth 1:10m (public domain)
Береговые линии, сухопутные границы, морские границы (пунктир, голубой), границы регионов (по запросу),
полигоны стран (`ADM0_A3`: `RUS`, `USA`, `NOR`…). Все линии **прорисовываются** вдоль земли от начала к концу
(не появляются прозрачностью).
Точность 1:10m — около километра, поэтому на планах уже ~24 км движок сам плавно гасит эти линии (полностью к 12 км):
на масштабе города границу показывай своей линией `line` по реальным координатам или подписями берегов.

### Палитра (`theme.ts`)
| Роль | Цвет |
|---|---|
| Главный объект, линия расстояния, крупные числа | жёлтый `#FFD24A` (`accent`) |
| «Другая сторона», спорное, опасность | красный `#FF5A4E` (`red`) |
| Вода, морские границы | голубой `#8FD3FF` (`blue`) |
| Сухопутные границы | белый 72% с тёмной подложкой |
| Плашки | `rgba(8,12,18,.82)` |

Максимум **две** выделенные страны в кадре: обычно `accent` — наш герой, `red` — сосед.

### Шрифты
- **Inter** 400/600/800 — подписи, плашки, HUD.
- **Playfair Display** 600/800 (+курсив) — хук, крупные числа, главы, водные объекты (курсивом).

### Подписи (`label.kind`)
| kind | Вид | Для чего |
|---|---|---|
| `country` | ПРОПИСНЫЕ, Inter 800, 40px, разрядка 0.24em (сжимается при появлении) | страны |
| `region` | ПРОПИСНЫЕ, Inter 600, 24px, белый 85% | штаты, области, полуострова |
| `water` | Playfair курсив, голубой, 34px, можно в 2 строки через `\n` | моря, проливы, заливы |
| `place` | белая точка + текст Inter 600 30px справа (`side`) | посёлки, базы, маяки |
| `callout` | тёмная плашка с жёлтой полосой слева, до 520px | факт, привязанный к точке |

Подписи появляются за 0,45 с (прозрачность + небольшой сдвиг), никогда не мигают и не прыгают.
Не больше **5 подписей** в кадре одновременно. Подписи не должны перекрывать друг друга и ключевой объект.

### Элементы-«раскрытия»
- `distance` — дуга большого круга, рисуется от A к B (2 с), бегущая белая точка на конце, плашка с числом,
  которое **досчитывает** от 0 до значения («3,8 км»). Концы — точно на береговых линиях / объектах.
- `ring` — пунктирный круг радиуса N км с лёгкой заливкой: «всё, что в 50 км отсюда».
- `line` — произвольная линия (линия перемены дат, старая граница, маршрут), можно `dashed`, с подписью.
- `marker` — точка с пульсирующим кольцом + подпись.
- `country` — заливка 16% + светящийся контур, который прорисовывается; `focus: true` затемняет всё вокруг.

### Камера — главный приём стиля
- **Одна сцена = одно место.** Камера в каждом кадре **медленно наезжает** на это место (по умолчанию −7% ширины
  за кадр, с постоянной скоростью — без рывков).
- Камера задаётся как `{"center": [долгота, широта], "span": км_по_ширине_кадра}`.
- Если у кадра не указан `camera.from`, он **продолжает** с того места, где закончился предыдущий — монтаж
  выглядит как одно непрерывное движение.
- Переезд в другое место: мягкий ease-in-out; если места далеко, камера сама «приподнимается» в середине пути.
- Типовые масштабы: космос `20000–30000`, страна/регион `1500–4000`, пролив/остров `200–900`,
  посёлок `10–40` км.
- Наезд «из космоса в точку» — один кадр с `from.span ≈ 30000` и `to.span ≈ 1000`. Используется в холодном
  открытии и максимум ещё 1–2 раза за ролик.
- Внизу слева всегда HUD: масштабная линейка и координаты центра («65°46′ с. ш. 168°58′ з. д.»).

### Экранный текст (`onScreenText.style`)
| style | Вид | Когда |
|---|---|---|
| `hook` | крупный Playfair по центру, слова появляются по одному, цифры жёлтые | вопрос в холодном открытии |
| `number` | огромное жёлтое число внизу по центру + надпись над ним (`kicker`) | главное число раскрытия |
| `chapter` | слева сверху: «ГЛАВА 2» жёлтым + заголовок | первый кадр главы |
| `caption` | плашка слева снизу с жёлтой полосой | короткий факт, ≤ 8 слов |

Титульная карточка главы — `"kind": "title"` (карта размыта и затемнена, по центру «ГЛАВА N» + название),
2,5–3 с, `"transition": "fade"`.

## 3. Холодное открытие (первые 20–30 секунд)

1. **Кадр 1 — вопрос.** Глобус из космоса, камера начинает падать к месту. На экране `hook`: вопрос с числом
   («Почему 80 американцев живут в 3,8 км от России?»). Диктор произносит его же — дословно или почти.
2. **Кадры 2–4 — «странно, но правда».** Камера долетает, прорисовываются береговые линии и граница,
   появляется линия расстояния с числом. Ещё два факта, усиливающих странность.
3. **Кадр 5 — обещание.** «Чтобы понять, почему, нужно вернуться на…» — обрыв, затем титул.
Никаких приветствий, «подписывайтесь» и рассказов о канале в начале.

## 4. Сценарий

- ~1400 слов, 8–10 минут. Короткие предложения (8–14 слов). Одна мысль — одно предложение.
- Тон: спокойный документальный рассказчик. Без сленга, без восклицаний, без «друзья».
- **Новое раскрытие не реже раза в 60 секунд**: число, неожиданный факт, поворот истории, новая точка на карте.
  В `script.md` отмечай их `[РАСКРЫТИЕ]`.
- Структура: холодное открытие → 4–6 глав (каждая — новое место или новый слой истории) → финал,
  который возвращается к вопросу из хука и отвечает на него → одна фраза-послевкусие.
- Все числа проверены и записаны так, как читаются вслух (диктор читает «три и восемь десятых километра»,
  на экране «3,8 км»).
- Числа и расстояния считай по реальным координатам (`d3.geoDistance(a, b) * 6371`), а не по памяти.

## 5. Формат `shots.json`

```jsonc
{
  "meta": {"title": "…", "slug": "diomede", "lang": "ru"},
  "shots": [
    {
      "id": "s01",                       // по порядку: s01, s02…
      "narration": "Точная строка диктора.",  // одна строка сценария = один кадр
      "visual": "Что зритель видит (для человека)",
      "duration": 5.5,                   // оценка в секундах (~2,5 слова/с); после озвучки берётся из timeline.json
      "kind": "map",                     // "map" (по умолчанию) | "title"
      "camera": {"from": {"center": [-150, 45], "span": 30000}, "to": {"center": [-169, 65.8], "span": 1400}},
      "overlays": [                      // t, d — секунды от начала кадра
        {"type": "coast", "t": 3},
        {"type": "borders", "t": 0.3, "states": false},
        {"type": "country", "code": "RUS", "color": "red", "t": 0.8, "focus": false},
        {"type": "label", "text": "Россия", "pos": [-175, 66.6], "kind": "country", "t": 1.6},
        {"type": "marker", "pos": [-168.93, 65.76], "text": "Малый Диомид", "color": "accent", "t": 2},
        {"type": "distance", "from": [-169.03, 65.765], "to": [-168.95, 65.765], "text": "3,8 км", "t": 2.5},
        {"type": "line", "coords": [[-168.98, 65.5], [-168.98, 66.1]], "dashed": true, "color": "white", "text": "Линия перемены дат"},
        {"type": "ring", "pos": [-168.93, 65.76], "km": 5, "text": "80 жителей", "t": 0.5}
      ],
      "keep": false,                     // true — оставить уже нарисованные слои предыдущего кадра
      "onScreenText": {"text": "…", "style": "hook|number|chapter|caption", "kicker": "…", "t": 0.4},
      "title": {"kicker": "Глава 2", "text": "…"},   // только для kind: "title"
      "transition": "cut"                // "cut" | "fade"
    }
  ]
}
```
Правила:
- Координаты `[долгота, широта]` — всегда реальные (Natural Earth, Википедия), до 3–4 знаков для крупных планов.
- Пока камера на одном месте, ставь `"keep": true` — слои копятся, а не рисуются заново.
- В кадре **одно** главное раскрытие. `number` не ставится одновременно с плашкой `distance`/`ring` в той же зоне.
- Средняя длина кадра 4–8 с. Длиннее 10 с — разбей строку на две.
- Первые 3 кадра каждой главы: общий план → средний → крупный.

## 6. Привязка к озвучке
`npm run align -- <slug>` (faster-whisper, русский, пословные метки) → `timeline.json`.
Каждый кадр начинается с первого слова своей строки; последний длится до конца аудио + 2 с.
Если строка не нашлась — скрипт предупредит и оценит начало; проверь, не изменил ли диктор текст.

## 7. Рендер
```bash
npm run prep -- <slug>                                              # снимки + геоданные + тайминг
npx remotion render src/index.ts MapExplainer out/video.mp4         # весь ролик
npx remotion render src/index.ts MapExplainer out/video.mp4 --frames=0-1799   # первая минута
npm run studio                                                      # просмотр в браузере
```
Снимки кэшируются в `public/tiles/` (не коммитятся).

## 8. Чек-лист проверочных кадров (смотреть самому, каждый раз)
- [ ] Снимок резкий, без чёрных полос, пикселей и швов; виньетка на месте.
- [ ] Границы и береговые линии совпадают с берегом на снимке.
- [ ] Все тексты по-русски, кириллица в нужном шрифте (не системный), без опечаток, «км», запятая в дробях.
- [ ] Подписи не перекрываются и не обрезаны краем кадра; не больше 5 в кадре.
- [ ] Концы линии расстояния на берегах/объектах; число в плашке совпадает с диктором.
- [ ] Цвета только из палитры; максимум две выделенные страны.
- [ ] HUD (масштаб + координаты) виден на карте и скрыт на глобусе/титрах.
- [ ] Хук читается целиком, числа в нём жёлтые.
Нашёл отклонение — исправь `shots.json` (или движок, если это общий дефект стиля), перерендерь и проверь снова.

## 9. `upload.md`
- 3 названия < 60 символов, с числом, без кликбейта-лжи; одно — вопросом.
- Описание: 2–3 предложения-хука, затем главы с тайм-кодами (`00:00 Вступление` …, первая обязательно 00:00),
  затем «Источники: снимки NASA GIBS / Blue Marble, Landsat WELD; карты Natural Earth».
- 15 тегов: русские + пара английских.
- Идея превью: спутниковый снимок места, одна жёлтая линия расстояния, 2–4 слова огромным шрифтом
  (число + интрига), одна стрелка или красная граница. Без лиц.
